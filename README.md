# QuickNotes

QuickNotes is a simple and responsive note-taking web app that allows users to create, organize, search, and delete notes. Notes can be grouped into Personal, Work, or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add new notes
- Personal, Work, and Study categories
- Delete individual notes
- Search notes by text
- Validation for empty notes
- Maximum 200-character note limit
- Automatic note count
- Notes saved using localStorage
- Responsive design for small screens
- Category-specific note styling

## How to Run the Project Locally

1. Download or clone this repository.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` with Live Server.
4. Use the QuickNotes app in your browser.
